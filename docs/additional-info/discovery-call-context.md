# Context from the discovery call

**Recruiters need to find suitable people already in their pool when a role opens.** The call described a fictional team of five using LinkedIn, conferences, referrals and Comeet. The [written assignment](../../assignment/index.html) defines the deliverables.

## The recruiting problem

Each role has an owner, but contacts are scattered and Comeet's filtering is not precise enough. More candidates would add screening work without solving that problem.

## Pain points

- **Too much to screen:** little help choosing whom to approach first.
- **Forgotten attendees:** each event has its own spreadsheet; useful contacts disappear from view.
- **Hidden references:** employees may know sourced people who have never applied.

## What the solution needs to do

- **Explain fit:** attendance proves neither ability nor interest. Missing profiles need review.
- **Collect contacts once:** feed registration into a shared pool.
- **Follow recruiting work:** handle repeat attendees, old events, new roles and people already in Comeet.
- **Find reference leads:** use held data and employee knowledge, without messaging candidates. A connection is not an endorsement.
- **Connect existing tools:** move data between systems so recruiters manage each person in fewer places.
